# Pi hole  
This is the pi hole made by raspberry pi zero 2 w which can block ads on my devices.
Pi-hole is a free, open-source network-level advertisement and Internet tracker blocking application that acts as a DNS sinkhole.  It is designed to run on low-power embedded devices, such as the Raspberry Pi, or any Linux system. 
Some terminal codes and files on internet are used on it.

**How to make** 

To make it you should download imager first from where you can download one suitable raspberry pi OS and later on download some files and give some premitions and need to use some terminal codes which are easily avilable on internet.
